# Raindrop Chimes

Toy project to make beautiful sound from simple mathematical rules.

For algorithm details and samples see http://www.jenskoeplinger.com/RC/raindrops.html

The project is being revamped (2026) into a codebase that separates
composition, synthesizer, and output file format. See
[docs/REVAMP_PLAN.md](docs/REVAMP_PLAN.md).

- [legacy/](legacy/) -- the original 2011 single-file program ("DingDong Doodle"),
  kept as-is. See [legacy/README.md](legacy/README.md) to compile and run it.
- [legacy/examples/](legacy/examples/) -- tunes rendered over the years, and the
  historical source snapshots (`sndharmonics*.source*.tar.gz`) that produced the
  earliest ones.
